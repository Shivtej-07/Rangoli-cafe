# 🪔 Rangoli Cafe & Restaurant (रंगोली कैफे)

A modern, professional, visually warm single-page website for **Rangoli Cafe & Restaurant**, a women-owned, LGBTQ+ friendly Indian restaurant and cafe in Vashist, Himachal Pradesh (rated 4.8★ from 500+ Google reviews).

![Rangoli Cafe Preview](https://images.unsplash.com/photo-1517248135467-4c7edcad34c4?auto=format&fit=crop&w=1200&q=80)

## 🌟 Brand & Features

- **Identity**: Women-Owned 👩‍🍳 • LGBTQ+ Friendly 🏳️‍🌈 • Mountain Views 🏔️ • Fresh Local Produce 🌿 • Pet Friendly 🐾
- **Location**: Opposite Yogashala, Jogni Waterfall Road, Vashist, Himachal Pradesh 175103
- **Google Rating**: 4.8 / 5.0 (510+ Reviews)
- **Tech Stack**: React 19, Tailwind CSS v4, Vite, Lucide Icons
- **Key Sections**:
  - 🏡 **Hero**: Full-bleed terrace photography, star rating badge, bilingual headline, dual CTAs.
  - 🎖️ **Trust Strip**: Highlights women-owned, LGBTQ+ friendly, fresh local ingredients, pet-friendly badges.
  - 📖 **About**: Warm story of Rangoli Cafe, stats, and hospitality values.
  - 📜 **Menu**: Categorized price list (Breakfast, Homestyle Mains, Cafe & Snacks, Beverages) with search, dietary filters (Veg / Non-Veg / Vegan), and chef tags.
  - 🖼️ **Gallery**: Masonry grid with category filtering and interactive full-screen Lightbox modal.
  - ⭐ **Reviews**: Google Maps review breakdown and interactive guest carousel.
  - 🕒 **Hours**: Live operational status calculator (*"🟢 OPEN NOW"* / *"🔴 CLOSED NOW"*) based on local time.
  - 📍 **Location Map**: Directions, landmarks, copy address shortcut, and responsive map embed.
  - 📅 **Reservation Form**: Client validated booking form with success overlay and WhatsApp backup.
  - 📱 **Floating Actions**: WhatsApp button & mobile sticky call bar.

## 🛠️ Local Setup & Run

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Shivtej-07/Rangoli-cafe.git
   cd Rangoli-cafe
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
